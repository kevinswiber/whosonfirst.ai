### Credential injection at the egress proxy

- **Accept · Claude Code cloud sessions, hosted coding agent proxy.** A network secret is stored on a cloud environment with the hosts it is for. Anthropic’s agent proxy adds it to requests for those hosts after they leave the session’s VM. For a key sent in a header, the form names the header: Authorization unless the person changes it. Anthropic-hosted environments only. The proxy does not attach a secret to GitHub, the Anthropic API, the public package registries the page lists or a setup script’s requests. A secret applies in every session in the environment, whoever started it. The form offers other secret types, and the page does not say where those put the value. [Configure cloud environments](https://code.claude.com/docs/en/cloud-environments)
- **Accept · Codex Cloud environments, hosted coding agent proxy.** A network secret has a key, a value and allowed domains. Programs in the environment receive a placeholder, and the proxy substitutes the real value in requests to the allowed domains, during setup and during tasks. Substitution works for HTTPS on port 443, through the environment’s proxy. The page does not say where in a request a placeholder is replaced. An environment variable, the other way to supply a value, is passed to programs directly. A person’s own network secrets are saved in a Personal vault and use the environment’s allowed destinations. [Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments)
