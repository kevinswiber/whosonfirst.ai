# Sources for the adoption record

Every source considered for [the adoption record](README.md): what it can say, how it is read, what it costs, and what its terms allow. The site will show what it collects, so a source whose terms forbid republishing is of no use however good it is.

Each entry says how much of this was checked. **Read** means the terms or the documentation were read on 13 November 2026. **Not read** means they were not, and have to be before the source is relied on. Nothing below is legal advice.

## Paid, and not recommended

| Source                                                                | Why not                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Crunchbase                                                            | **Read,** from its knowledge base: its data is licensed for the uses in a subscriber’s order form, republishing needs written consent, and anything shown needs a followed link to Crunchbase. It also records companies, not protocols: it cannot say who supports DPoP |
| Technology detection (BuiltWith, Wappalyzer, SimilarWeb and the like) | **Not read.** They detect what a page loads. A grant type is not visible in a page                                                                                                                                                                                       |
| Analyst firms (Gartner, Forrester, G2)                                | **Not read.** They rate products, under license, and the site describes vendors only from their own documentation                                                                                                                                                        |
| Internet-wide scanners (Shodan, Censys)                               | **Not read.** They could find every exposed identity server. Scanning is not what this site is, and a count of exposed servers is not a count of use                                                                                                                     |
| Social platforms’ APIs                                                | **Not read.** Paid, changeable, and they measure talk, which the record already holds at arm’s length                                                                                                                                                                    |

One private use of paid data is reasonable and would never be shown: checking which organization owns which, so that two products of one company are counted once. The ledger already has to do this by hand.

## Rules a source has to meet

1. **Public.** A reader can open it without an account.
2. **Free to cite.** Its terms allow a count made from it, or a short quotation, to be shown with a link.
3. **Checkable again.** A script can ask it the same question next month.
4. **Its own words.** A vendor is read from its own pages. A third party’s account is recorded as _reported_, as the site already does.
5. **Asked politely.** Only addresses that exist to be read by software, a handful of requests each, and a name that says who is asking once the census runs on a schedule.
